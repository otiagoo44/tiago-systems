# Tiago Systems

Landing de Tiago Systems y presentación de DentFlow, construida con React, TypeScript y Vite.

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm run preview
```

Vercel puede importar este repositorio como proyecto Vite. El comando de build es `npm run build` y el directorio de salida es `dist`.

## Contenido

- Las imágenes de la sección DentFlow son ilustraciones con datos ficticios. Las capturas privadas del CRM se mantienen fuera del repositorio.
- La ventana del hero es una ilustración del flujo.
- El botón de salida abre DentFlow.
